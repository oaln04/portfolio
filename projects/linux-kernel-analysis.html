Comprehensive OS Case Study — Debian 13.4 "Trixie"

Overview

A comprehensive technical and ethical analysis of Debian GNU/Linux 13.4 "Trixie", conducted as part of the Operating Systems Fundamentals course (CSCI 312). The report examines Debian's internal operating system mechanisms, evaluates its design principles, and documents hands-on experimentation through a virtualized deployment.

Key Technical Areas

Scheduler

EEVDF (replaced CFS)

Kernel

Linux 6.12 LTS

Architecture

x86-64, ARM64, RISC-V

VM Platform

Oracle VirtualBox

Process & Thread Management

The analysis covers Debian's unified task_struct representation, the NPTL threading model, and the historic transition from the Completely Fair Scheduler (CFS) to the Earliest Eligible Virtual Deadline First (EEVDF) algorithm. EEVDF improves latency and fairness for modern workloads by introducing eligibility filters and deadline-based selection.

Synchronization & Memory

The report details the full hierarchy of kernel locking mechanisms — mutexes, semaphores, spinlocks, read-write locks, and RCU — alongside the lockdep framework for deadlock prevention. Memory management analysis covers virtual address spaces, four-level page tables, the Buddy System allocator, SLUB object allocator, demand paging, Copy-on-Write, and LRU-based page replacement.

Security & Ethics

The security model addresses user/group-based access control, pluggable authentication, least privilege principles, and kernel-level enforcement through Linux Security Modules. The ethical analysis examines Debian's GPL licensing, user privacy commitments, security patch governance, and the Debian Social Contract.

Implementation & Testing

Debian 13.4 was deployed on a VirtualBox VM with 1GB RAM and 1 vCPU. The team used top, htop, strace, stress, and stress-ng to observe process lifecycle management, system call behavior, memory allocation under pressure, and scheduler response to high-load conditions.

Markdown Screenshot

A lightweight Tauri screenshot app that copies AI-friendly Markdown image references by default.

Overview

Markdown Screenshot is a Windows-first desktop utility inspired by Greenshot and the Snipping Tool. It runs in the tray, opens a transparent region-selection overlay from a global hotkey, saves the selected screenshot locally, and copies a Markdown image reference to the clipboard.

Technical Stack

Shell

Tauri v2

Frontend

React, TypeScript, Vite

Native Core

Rust, xcap, image, chrono

Desktop APIs

Tray, global hotkey, clipboard

v1 Features

Phase 1 Core Loop

  • Tray app Capture Region and Quit menu actions
  • Hotkey Global Ctrl+Shift+S shortcut
  • Overlay Fullscreen dimmed selection layer with drag rectangle
  • Capture Real PNG screenshots saved under a screenshots folder
  • Clipboard Copies ![screenshot](screenshots/YYYY-MM-DD_HH-mm-ss.png)

Why It Exists

Raw screenshots are useful, but pasting image data into AI tools can be heavy. This app keeps the image on disk and copies a short Markdown reference, making screenshots easier to share in prompts, notes, bug reports, and technical documentation.
